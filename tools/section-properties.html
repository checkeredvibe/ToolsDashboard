Calculations used & sources

Equations (composite sections via the parallel-axis theorem)

  • Local axes: x horizontal, y vertical, origin at the lowest point of the section; ȳ measured from y = 0. All dimensions in mm.
  • Iₓ = ∫ y² dA (about the horizontal centroidal axis — strong axis for upright sections), Iᵢ = ∫ x² dA (vertical centroidal axis — weak axis)
  • I = Iℂ + A d² (Steiner / parallel-axis theorem, d = distance between axes)
  • Wₓ = Iₓ / cₓ, Wᵢ = Iᵢ / cᵢ, with c the distance from the centroid to the extreme fibre
  • I-beam: Iₓ = [b h³ − (b−t_w)(h−2t_f)³] / 12, Iᵢ = [2 t_f b³ + (h−2t_f) t_w³] / 12
  • Flat bar b×h: A = bh, Iₓ = b h³/12, Iᵢ = h b³/12
  • Tubes (outer minus inner): round tube A = π(d²−d_i²)/4, I = π(d⁴−d_i⁴)/64; square/rectangular tube subtracts the inner rectangle
  • Bulb profile (Hollandprofiel): predefined standard sizes HP 60x4–HP 430x20; geometry = web rectangle (h−r_b)×t plus upper half-disc of radius r_b; half-disc: A = πr_b²/2, ȳₒ = +4r_b/(3π) above the circle centre, Iₓℂ = r_b⁴(π/8 − 8/(9π)), Iᵢℂ = πr_b⁴/8

Sharp-corner idealisation: root fillets of hot-rolled profiles are neglected, so computed bulb values are a few percent below catalogue values (e.g. HP 120x6: model A = 7.82 cm² vs catalogue 9.32 cm², Iₓ = 104 vs 133 cm⁴).
