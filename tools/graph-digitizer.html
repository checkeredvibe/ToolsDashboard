Graph Digitizer

Digitize scanned or printed graphs: upload an image, click the 4 corners of the plot frame and enter the axis values there (handles skewed/perspective scans and logarithmic axes), then click any point on the graph to read its value. Multiple curves per graph, re-plot, CSV and PNG export. Fully offline — the image is read locally and never leaves your machine. All values in SI units.

Input

Graph image
No image loaded — or drag & drop an image onto the graph.
Supported: .png .jpg .jpeg .gif .webp .bmp. Read locally with FileReader; nothing is uploaded.
Axes
Log axes need corner values > 0; the mapping is done in log₁₀ space.
Calibration — 4 corner points
Upload an image, then click the plot-frame corners in order: 1 bottom-left, 2 bottom-right, 3 top-right, 4 top-left. Drag a marker to adjust it.
A projective transform (homography) is fitted through the 4 points, so skewed/perspective scans are mapped correctly.

Calculations used & sources

Equations

  • Projective transform (homography) H with h₃₃ = 1, fitted from the 4 clicked pixel–data corner correspondences by solving the 8×8 linear system H · (u, v, 1)ᵢ ≈ (x, y, 1) (Gaussian elimination): (x, y) = pixel→data, inverse used to draw the grid.
  • Logarithmic axes: the same homography is fitted in log space, x = 10^(xₖₒg), y = 10^(yₖₒg), so semi-log/log-log graphs digitize correctly.
  • Tick placement: 1–2–5 “nice” steps for linear axes; decades with 2…9 minor ticks for log axes.
  • Calibration residual: max reprojection error of the 4 corner points (pixel→data→pixel), in px.

All axis values and results are in SI units; readouts use the shared SI.format helper.

Sources

  • No external references (per engineer): standard projective geometry — a homography is uniquely determined by 4 point correspondences.
  • Fully offline: image read with FileReader, all computation in the browser, no network.
