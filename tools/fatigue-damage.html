Calculations used & sources

Equations (DNV-CG-129, July 2026 ed., Appendix C)

  • Weibull long-term stress-range distribution (App. C 2.1): Q(Δσ) = exp(−(Δσ/q)^ξ), q = Δσ₀ / (ln n₀)^(1/ξ), equivalently Δσ = Δσ₀ · [ln n / ln n₀]^(1/ξ)
  • Weibull slope parameter from rule length: ξ = 2.21 − 0.54·log₁₀(L)
  • Damage estimate, one-slope S-N curve (App. C 2.2): D = (N_D / K₂) · q^m · Γ(1 + m/ξ) ≤ η
  • Total cycles in design life: N_D = 31.557·10⁶ · T_D · f₀ · v₀, with average zero-crossing frequency v₀ = 1 / (4·log₁₀(L)) (Hz)
  • One-slope S-N curve (Sec. 2.3, Table 1, FAT X row): N = K₂ · Δσ^(−m), Δσ in MPa (N/mm²); m = 3: log K₂ = 6.301 + 3·log₁₀(X); m = 5: log K₂ = 7 + 5·log₁₀(0.585·X)
  • Fatigue life (linear accumulation / Miner): T_f = T_D / D; equivalent constant-amplitude stress range S_eq = (D·K₂ / N_D)^(1/m) (D = N_D / N(S_eq))
  • Γ evaluated with a Lanczos approximation (complete gamma function).

Stresses are in MPa (N/mm²) because the DNV S-N curves define K₂ in (N/mm²)^m; f₀ is entered in % and used as a fraction. One-slope S-N curves give conservative fatigue-life estimates compared to two-slope curves (App. C 2.2).

Sources

  • DNV-CG-129, July 2026 edition — Appendix C 2.1 (Weibull long-term stress distribution), Appendix C 2.2 “Damage estimate for one-slope S-N curves and Weibull distribution”, Sec. 2.3 Table 1 (S-N curve parameters, FAT classes B1–F and FAT X).
  • Engineer’s Excel automation of App. C 2.2 (internal, 2026) — used as the verification example: Δσ₀ = 160 MPa, X = 62 MPa, f₀ = 50 %, T_D = 25 y, L = 150 m, n₀ = 10ᵗ, m = 3 → D ≈ 0.652, fatigue life ≈ 38.3 y.
