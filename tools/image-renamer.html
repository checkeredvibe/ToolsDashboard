Image Renamer

Rename the images in a folder — manually one by one with a live preview, or in batch with a prefix + counter pattern. Fully offline: files are read and renamed locally in your browser (Chrome/Edge, File System Access API); nothing is uploaded. File sizes use SI prefixes (1 kB = 1000 B).

Input

Folder
Supported: .jpg .jpeg .png .gif .webp .bmp. Files never leave your machine.
Renaming mode
Switch modes any time after opening a folder.
Manual name
Enter applies the rename. Enter with an empty field skips the image (old name is kept).
Batch pattern
New name = prefix + counter + extension, e.g. IMG_0001.jpg (width 4). Counter increases by step per image.

Calculations used & sources

Equations

  • No engineering calculations — this tool only renames files locally.
  • Manual mode: newName = typedName + extension
  • Batch mode: newName = prefix + pad(counter, width) + extension, with counter ← counter + step per image
  • File sizes are shown with SI prefixes (1 kB = 1000 B) via SI.format from assets/js/tools.js

The rename itself is performed by the browser with FileSystemFileHandle.move(newName).

Sources

  • No external references — this is a file utility, not a calculation tool.
  • File System Access API (W3C draft community report; implemented in Chrome/Edge): window.showDirectoryPicker(), FileSystemFileHandle.move().
  • Fully offline: folder contents are read locally and previews use object URLs; no network requests are made.
